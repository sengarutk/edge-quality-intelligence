# Data Card

## Visual scores (real)
* Source: MVTec AD, categories bottle, cable, carpet, grid, hazelnut, leather, metal_nut.
* Model: PatchCore (ResNet-18, 10% greedy coreset, 224x224), one model per category, fitted
  on a random 80% of the good training images (seed 2026).
* Normalization: `v = min(1, 0.5 d / d99)` with `d99` from the held-out 20% of training images.
  No test image is used for any calibration.
* Pools per category: good test images, defective test images, and good test images with a
  synthetic specular highlight (3 per image). Stored in `results/score_bank/<category>.npz`,
  summary in `results/score_bank/summary.json`.

## Workloads (synthetic timelines)
Defined in `configs/scenarios/*.yaml`, generated by `src/experiments/workloads.py`.
Each run is 9,000 frames (5 min at 30 Hz); events are placed at random per unit.

| Workload | Events | Ground truth |
|---|---|---|
| nominal | none | none |
| transient_glitches | 40 glare bursts (1-3 frames), 10 blur bursts (1-2 frames) | none |
| sustained_defects | 8 defects (60-240 frames) | defects |
| multimodal_faults | 5 defects with mechanical fault, 3 mechanical faults, 10 glare events (10-60 frames) | defects and mechanical faults |
| degraded_inputs | 6 defects, 6 blur and 2 dark windows, 4 current dropouts, 2 temperature drift ramps | defects |
| state_transitions | 2 maintenance and 2 idle windows with glare and mechanical load inside maintenance, 6 defects while running | defects while running |

Visual scores are sampled independently per frame from the matching pool, so the temporal
correlation of real video is not reproduced. Event densities are far higher than on a real line.

## Units and seeds
An experimental unit is (category, seed) with seeds 11, 23, 37: 21 units per cell, identical
inputs for every policy (paired design).
